# Jiaheng Zheng — Personal Website

Static academic homepage deployed with GitHub Pages.

## Files
- `index.html` — homepage
- `cv.html` — web CV
- `cv.pdf` — downloadable CV
- `images/` — portrait and university logos

## Local preview
Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
